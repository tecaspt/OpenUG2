## Inputs and behavior to script

FE: Left/Right changes track/car or current option; Up/Down switches the two editable option rows;
Enter advances Track → Track Options → Mode Options → Car → launch. Esc/pad B/touch Back goes back.
Both options pages edit the same persistent laps/difficulty values. Unsupported rows are display-only.
Touch side zones edit, center accepts; touch rows select the editable row. Back is always at virtual
x=24..170, y=440..472 (640x480 fitted to the window), including when authored presentation fails.

Results: Enter/pad A/tap Next opens UI_postrace. R/pad X/tap Restart restarts directly.
Post-race carousel: Left/Right selects Restart / Continue / Quit to Main; Enter/pad A/center tap selects.
Esc/pad B/Back requests Quit to Main. Each action is returned once and closes the screen.
Unknown opponent rows are omitted. The runtime check does not load a world/car: its black background
behind Car Select is expected; main provides the frozen-world preview.
